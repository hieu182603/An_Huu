# An Hưu — Nền Tảng Lập Kế Hoạch Nghỉ Hưu & Quản Trị Tài Chính Dài Hạn

An Hưu là nền tảng web hiện đại hỗ trợ người dùng xây dựng mục tiêu tài chính nghỉ hưu, tính toán lộ trình tích lũy, thử nghiệm kịch bản tài chính và đồng hành cùng trợ lý AI thông minh.

## 🚀 Công Nghệ Sử Dụng

- **Frontend:** React 18, TypeScript, Vite
- **Styling:** CSS Modular / Custom Design System (Warm, Tin cậy, Chuẩn mực tài chính)
- **Routing:** React Router v6
- **Biểu đồ & Phân tích:** Chart.js / Recharts
- **Icons:** Lucide React
- **Testing:** Playwright E2E & Responsive Audits

## 🌟 Tính Năng Chính

- **Landing Page:** Giới thiệu nền tảng, công thức lập kế hoạch, câu chuyện thương hiệu và công cụ tính toán nhanh.
- **User Dashboard:** Bảng điều khiển tài chính cá nhân, theo dõi tiến độ tích lũy, quỹ hưu trí và khuyến nghị danh mục.
- **Trợ Lý AI An Hưu:** Tư vấn giải pháp hưu trí, phân tích kịch bản tài chính thực tế và giải đáp thắc mắc.
- **Admin Portal:** Quản lý người dùng, thống kê phân khúc khách hàng và giám sát hoạt động hệ thống.

## 📦 Cài Đặt & Chạy Dự Án

### Yêu cầu
- Node.js >= 18
- pnpm hoặc npm

### Khởi chạy Frontend
```bash
cd frontend
npm install # hoặc pnpm install
npm run dev
```

Truy cập tại `http://localhost:5173` hoặc cổng hiển thị trên terminal.
